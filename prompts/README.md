# Prompt archive

These are the prompts used during the private pet build. `rows/` holds the initial animation prompts; `row-retries/` and `look-anchor-repairs/` preserve later targeted corrections so the evolution of the result is visible.

References such as “canonical base,” “action reference,” “layout guide,” “approved strip,” and “contact sheet” refer to private images that are intentionally absent from this repository. Their external provenance belongs in [`../references.md`](../references.md).
